# 義工設定與日常操作指南

此候選版本在隔離環境驗證；尚未發布到正式站。原有動物、助養帳目、出席及報名 ID 保留。

## 管理員：建立及發布政策

1. 開啟「義工政策設定」。先選模板，再編輯時間、星期、地點、有效日期、容量、職務、資格、報名窗口、補位及備註。未決欄位會列出原因；填妥及明確選定後可由同一位管理員發布，不需要開發者或第二位批准者。
2. 「共用／場地來源」可登記具名稱、時區及地點的服務場地、課程資格，並從已儲存草稿建立預覽後發布共用或場地來源。模板的繼承選擇會顯示來源；發布產生完整快照，舊場次不會隨來源編輯改動。
3. 儲存草稿後使用模擬器，選真實核實身份、場次及模擬時間。模擬不佔位、不接受條款，也不發訊息。
4. 建立影響預覽，檢查既有名單、人數、資格例外與重疊。明確選擇套用的未來場次；預設保留未選場次的版本。填寫發布理由並確認。
5. 若預覽過期、名單改變或其他人已編輯，重新載入比較，再建立新預覽。不可略過衝突。
6. 從模板生成未來活動。每日共享上限使用「每日設定」的獨立預覽／發布，清楚選擇場地、日期、不同人或人次及計算範圍。
7. 回復政策時把舊版本複製成新草稿，再預覽及發布；不刪除或修改舊版本與出席事實。

## 職員：核實、報名及跟進

- 義工先驗證電郵並認領本人身份。職員在「身份與資格核實」按證據確認級別、出生日期、課程有效期、加入日期及歷史覆蓋範圍。未知歷史保持未知，不能當零出席。
- 「舊報名身份核對」只連結有證據的同一人；相同名字或電郵不會自動合併。連結保留原有提交資料。場次須有已發布政策，義工本人須登入確認最新條款，才能按政策批准。
- 義工可查看級別、核實課程、服務紀錄、開放時間及剩餘名額，選崗位與備註並接受適用條款。備註不授予技能。重試同一請求不產生第二份報名。
- 批准、候補補位及改期都會重新檢查身份、資格、名額、每日上限及重疊；職員不能繞過政策。需要修改業務規則時由管理員建立新的政策版本。
- 使用月／週／日／列表月曆查看團體訪客與義工分開的數字、核心人手不足及資格例外。「今日待辦與通知」連到實際報名詳情，記錄聯絡／核實結果及重試失敗通知。
- 完成跟進不代表已批准、已補足人手或訊息已送達。資格例外仍須依核實流程解決。
- 團體詢問由核實申請人提交，職員確認實際人數後才切換適用情況。移動／改期先預覽、再確認，保留原始報名與變更紀錄。
- 只為已發生且獲批准的服務記錄出席。更正須有理由及最新版本；取消與出席競爭時只會保留一致結果。

## 月度評核及通知

管理員編輯出席計次、月份／場地範圍、晉升門檻、資深年資、恆常級別觀察期、提醒門檻、評核日及香港時間。未決欄位會阻止發布。觸發方式必須二選一：

- 「每次核實出席」在不可變出席紀錄落帳後計算第 N 次，只採用當日最新生效政策；若最新政策改為月度模式，舊的逐次政策不會繼續晉升。
- 「每月評核」只在已完成月份的評核中晉升。逾指定日／時才啟動工作程序仍會補跑；短月份按「最後一日」或「略過」設定處理。

新人達門檻升為恆常義工時會留下級別歷史及稽核紀錄。資深年資必須有職員核實的加入日期及歷史覆蓋，亦須完成已設定的恆常觀察期；系統只建立具政策版本及證據快照的候選，管理員仍須在人員核實流程手動批准資深級別。未知資料不會推算、不會當零出席，資深亦不會自動降級。

逐次核實模式亦有月度對帳：已核實歷史達到該月份固定政策門檻、但尚未晉升的人員，可在月度對帳補回晉升，並留下獨立對帳紀錄；不回寫舊級別事實。合計政策只能選合計範圍，分開政策只能選相應貓／狗舍，錯誤範圍會被拒絕。

每個已完成月份固定首次採用的政策版本；重跑不會換版本，也不會重複同一人、月份及通知種類。通知分為等候、處理中、供應商已接收、失敗；只有實際送達證據才能稱已送達。測試模式只建立佇列並使用本機測試接收器，不發真實訊息。正式電郵必須先配置電郵傳送；目前沒有 WhatsApp 傳送器，系統會拒絕把 WhatsApp 發布成正式渠道。職員可在待辦頁重試失敗通知；設定、預覽及 dry-run 不會造成真實發送。正式工作程序須配置一名明確且仍有效的系統管理員，帳戶被撤銷或缺失時會停止而不會任選其他管理員。

## 實習、動物及助養

- 實習在獨立申請／審批頁處理；管理員發布收生設定，職員核實獸醫學生與在學證據。附件私有；申請不佔一般義工名額。原有紙本表格尚未提供，不能聲稱已逐欄轉換。
- 動物先存草稿，再預覽及發布。圖庫可排序、選焦點、填雙語替代文字／來源及審核狀態；只有核准並發布的圖會公開。主圖與圖庫不以虛構動物补空缺。
- 職員記錄指定助養 proof 及配對；司庫／管理員按最新版本核實該 proof。退款保留原收款與退款事實，收據按保留淨額重發。未付款月份是服務跟進，不代表欠債。
