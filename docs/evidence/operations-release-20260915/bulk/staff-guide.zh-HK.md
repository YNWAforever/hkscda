# 義工活動工作台：職員操作指引

適用於本次本機驗證的候選版本。正式環境須先按發布程序批准及部署。所有日期與時間均以香港時間顯示。

## 日常查看及選取

1. 開啟 `/admin/volunteers/activities`。預設今天起30天，可切換表格／月曆、上一期／下一期、歷史或所有日期。
2. 搜尋同時涵蓋活動名稱與地點。按收容所、模板、團體安排、狀態、政策及最低人手篩選。人手差額使用已發布政策的崗位最低數，沒有猜測門檻。
3. 每頁25場。勾選可保留跨頁項目；「選取本頁」只加入本頁。按「鎖定已選跨頁項目」或「鎖定所有符合條件」，伺服器儲存當時確切場次及版本。新加入的活動不會自動入選。改動篩選會清除選取。
4. 按活動名稱開啟詳情，才載入報名、出席及分頁操作紀錄。詳情報名另分頁。Esc關閉並保留篩選及頁碼。月曆只呈現本頁活動；其餘活動須翻頁。手機略去空日期格。

## 產生四星期活動

1. 選「批量產生活動」，選已發布模板，輸入開始日期，按「四星期」。可選星期、結束日期及排除日期。
2. 預覽每個日期：時間、收容所、有效政策、容量，以及封閉日期／已有場次等不能產生的原因。
3. 同一天的場次為一個獨立執行組，每組最多100場。不會將同一天拆組以繞過每日限制。超過100場的同日選取會被拒絕，必須收窄。
4. 逐組閱讀、勾選已檢查並執行。每組是一個獨立交易，不能把多組視為一個原子操作。
5. 操作及結果在伺服器保存。本頁網址包含操作編號，可關閉後返回、更新進度。回應丟失時先讀取進度，再重試原組，不能重複產生場次。

發布政策與發布活動不同：只有已完成營運決定、通過政策預覽及核准的政策可供產生。產生場次不會自行發布草稿政策。

## 草稿、複製及編輯

- 「建立草稿」保存不接受報名的活動，建立及稽核在同一交易。輸入香港日期時間，勿按裝置時區轉換。
- 發布草稿：鎖定草稿，選「套用已發布政策」，選有效政策、填原因並預覽。活動會採用模板時間、地點、收容所及容量；預覽顯示套用後資料及現有報名數。衝突不會默默撤銷已接受的報名。
- 「複製至指定日期」使用第一個已鎖定來源場次。舊活動沒有模板須明確選擇對應模板。每個目標日重新解析政策及產生新編號，不複製報名、條款同意或出席歷史。來源在預覽後變更會要求重新預覽。
- 「編輯說明」只改標題／說明。容量、資格與時間須透過已發布政策及影響預覽處理；規則本身在政策設定修改，不能在活動列表臨時猜測。

## 截止、取消及出席

- 「截止報名」須填原因，只阻止新報名，保留場次及現有報名。
- 「取消活動」須填原因，預覽現有報名。取消保留歷史，取消報名、稽核及職員跟進工作在同一交易。已有出席事實或已開始場次受保護。
- 出席操作先預覽。未開始不能記錄出席；未結束不能記錄完成／缺席。不合資格記錄會列出略過數；已記錄事實須選更正並填原因。更正新增歷史，不覆寫舊事實。
- 「待職員跟進」是工作佇列狀態，不代表通知已發送或送達。本次操作寫入既有 `volunteer_operation_changed` 工作佇列，由職員工作台跟進；不能將其說成供應商送達證據。

## 衝突與重試

資料、政策、每日規則、資格或同日報名在預覽後改變，該組顯示衝突，須重新選取／預覽。交易失敗會保留失敗進度，修復原因後可重試原組；更換內容須建立新預覽。權限在執行時重新檢查。5000場以上請收窄篩選，不會靜默截斷。
