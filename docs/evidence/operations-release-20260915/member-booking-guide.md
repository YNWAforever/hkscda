# 義工預約、改期及出席操作

此文件說明本次候選版本。測試全部使用獨立本機的合成資料；不代表正式政策已獲批准或已發布。

## 義工

1. 在 `/volunteer` 可先瀏覽場次。首次參與請以電郵登入並登記身份；已有身份的義工使用同一登入入口。
2. 可按活動名稱或地點、服務地點及香港日期搜尋，再使用上一頁／下一頁。搜尋先由伺服器篩選，每頁最多25個場次。
3. 選擇場次、崗位，閱讀該場次條款並確認。名額及資格會再次核對；只在政策准許且候補未滿時提供候補報名。
4. 「我的預約」與「服務紀錄」把即將參與與過往資料分頁載入，較新的過往紀錄不會擠走已預約的未來場次。
5. 取消是否可用由場次政策決定。不接受自行取消或已超過截止時間時，請聯絡職員。無限制取消設定仍須符合出席紀錄保障。
6. 改期入口在 `/volunteer/operations`。選擇現有預約及目的場次，預覽後閱讀並同意目的場次條款，填寫原因才可確認。預覽過期或資料改變時需要重新預覽。失敗時原預約保留；成功時留下目的條款同意及改期紀錄，不需先建立第二個重疊預約。
7. 團體服務請使用「團體服務查詢」。查詢或待核實申請不等於已確認團體。

## 職員

- 職員不能代義工接受新的目的場次條款。若需要新同意，請義工本人登入改期頁面處理。
- 候補按現行政策的先到先得次序處理；較早候補者目前仍符合資格及條款時，不能跳過他們批准較後申請。資格或名額不足不會自動轉成成功。
- 出席只能於場次開始後記錄；完成服務及缺席只能於場次結束後記錄。已有事實的更正須沿用附原因的更正流程，不可用取消或改期覆蓋出席歷史。
- 取消期限、團體共用總名額、新人每日計算方式、A情況資深名額、團體窗口及T−48h規則仍由已發布政策決定。未解決的營運設定不能用本機測試值代替。

## 發布順序

先套用 `20260914160716_volunteer_member_booking_correctness.sql`，再套用bulk後續遷移，通過能力檢查後才部署依賴新分頁RPC的應用程式。舊的預約及改期RPC簽名保留；已開啟的舊改期預覽可能需要重新預覽。正式環境的遷移、政策發布、預約或通知仍須另行批准。
